# Review of chapters 1 to 8

Date: 4 November 2026. Branch `review/ch01-08`, base `cde0368` (merge of the whole-book
review, PR #19). Work in progress: this file is updated with each commit.

Scope: chapters 1 to 8 of `source/data/chapters.json` (Algebra 1, Factors, Sets, Applied
Arithmetic, Statistics 1, Perimeter/Area/Volume, Statistics 2, Geometry 1: 52 lessons,
their steps, skill checks, takeaways, common mistakes, reference entries, toolkit methods
and 32 challenges), the 71 cards in `source/data/visual-cards-01-08.json`, and the written
practice rows for these chapters in `practice-01-04.txt` and `practice-05-08.txt`.

## Method

Every field of every item in scope was read. Every numerical and algebraic result in steps,
skill checks, challenges, toolkit examples, cards and written practice was recomputed with
python and sympy (expansions, factorisations, quotients, substitutions, inequalities,
Venn-region counts, percentage and compound-interest chains, areas, volumes, scale
conversions, means, medians, ranges, angle chains and Pythagorean lengths). SVG text
elements were parsed and compared with the step text. Narration is generated at build time
by `source/spoken.py`; the built `compiled-data.json` narration for chapters 1 to 8 was
scanned for mis-read symbols, units and currency.

Severity key: error (mathematically wrong or wrong answer key), misleading, spec, pedagogy,
narration, typo.

## Findings and fixes

### Mathematical correctness

No wrong answer key, wrong worked result, ambiguous skill check or wrong distractor was
found in scope. All 104 skill checks have exactly one correct option. All 32 challenges,
the toolkit examples and the practice answers recompute correctly, including 06-c02
(2A + 15P = 9399.11 from 2400 + 200π and 160 + 20π), 03-c04 (two valid arrangements with
club totals 54, 46, 42 and 55, 45, 42), 07-c03 (a = 4, b = 16; the mean-7 variant forces
non-integers), 08-c01 (65°, 65°, 50° and the SAS correspondence) and 08-c02 (6 m, 2 m,
4.8 m).
